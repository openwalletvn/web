# Chat Page — Groq + assistant-ui

## Task

Build a production-standard `/chat` page for openwallet.vn that lets users ask Vietnamese credit/debit card questions. Uses Groq LLM via Vercel AI SDK (protocol glue only — no Vercel infra), assistant-ui for the Thread UI, tool calling to fetch live card data from the existing OpenWallet API, and localStorage for chat history persistence. Includes a scope-locked Vietnamese system prompt, history truncation, IP-based rate limiting, and an offline eval harness for regression testing.

## Notes

- **Branch:** create and work on `feat/chat-page` from `main` before making any changes. All commits go on this branch
- **Commits:** commit after each logical step (deps, system prompt, API route, client component, page, eval harness). Separate commits — do not batch everything into one
- **Push:** push `feat/chat-page` to origin once all commits are done
- Vercel AI SDK (`ai`) is protocol glue only — not tied to Vercel platform infra
- `GROQ_API_KEY` is server-only — never use `NEXT_PUBLIC_` prefix
- Model name read from `process.env.EVAL_CHAT_MODEL` — not user-selectable
- History truncation to last 12 messages happens in API route before `streamText` call
- Tools should strip heavy/unused card fields before returning to LLM (reduce token usage)
- Phase 2 (out of scope): input classification guardrail, Upstash rate limiting, RAG for blog content, embeddable iframe widget
