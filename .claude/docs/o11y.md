# Observability (Langfuse)

All observability uses Langfuse direct HTTP ingestion — no SDK. The Langfuse JS SDK silently fails in CF Workers (GitHub issue #11984), so all integrations use `fetch` to `POST /api/public/ingestion` directly.

## Web Chat Tracing

**File:** `lib/langfuse.ts`

- `fetchSystemPrompt()` — fetches `chat-system-prompt?label=production` from Langfuse, 60s in-memory cache, falls back to hardcoded `SYSTEM_PROMPT` on error
- `sendChatTrace()` — sends trace with input/output/model/tokens/latency/finishReason/steps/promptVersion

**File:** `app/api/chat/route.ts`

- Calls `fetchSystemPrompt()` at request start
- Passes fetched prompt text to `buildSystemPrompt(pageContext, promptText)`
- Sends trace via `next/server after()` (non-blocking, fires after response sent)
- Trace tags: `['web-chat']`

**Trace fields:**

| Field | Source |
|-------|--------|
| `input` | Last user message text |
| `output` | Full assistant response |
| `model` | `EVAL_CHAT_MODEL` env var |
| `tokens.input` | `usage.inputTokens` from Vercel AI SDK `onFinish` |
| `tokens.output` | `usage.outputTokens` |
| `latencyMs` | `Date.now() - startTime` |
| `finishReason` | From `onFinish` |
| `steps` | `steps.length` (tool call count) |
| `promptVersion` | From Langfuse prompt fetch |

## Prompt Management

System prompt lives in Langfuse UI under **Prompt Management → `chat-system-prompt`**, label `production`.

- Fetched at runtime with 60s cache
- Version tracked per chat trace → enables prompt/quality correlation
- Hardcoded fallback in `lib/chat/system-prompt.ts` used when Langfuse unreachable

## LLM-as-Judge Live Evaluator

Configured in Langfuse UI → **Evaluators**:
- Evaluator: Hallucination (managed)
- Target: Live Traces, filter trace name = `chat`
- Model: Groq via OpenAI adapter (base URL `https://api.groq.com/openai/v1`)
- Variable mapping: `{{query}}` → input, `{{generation}}` → output
- Scores appear in **Evaluation → Scores** automatically on new chat traces

## Known Quirks

- `score-create` in batch ingestion (`POST /api/public/ingestion`) is silently accepted but never stored. Always use `POST /api/public/scores` for scores.
- Langfuse JS SDK fails silently in CF Workers — use direct HTTP fetch only.
